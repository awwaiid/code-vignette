# code-vignette
Monorepo of some experiments and art

Each directory is a separate project / experiment.

## Projects

### 🍽️ chompie
A code minimization tool that systematically reduces your codebase to the minimal subset that produces the same output. Uses bisection to find the smallest set of lines needed to pass tests or produce specific results. Written in Rust with comprehensive tests.

### ⌚ watchdex01
A Wear OS push-to-talk capture app: hold the watch's side button to record audio, release to ship it to the paired phone over the Wear Data Layer. Mirrors the pebble01 / index01 ring flow. See [watchdex01/README.md](watchdex01/README.md).
